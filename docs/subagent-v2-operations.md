# Sub-Agent V2 运维说明

## 执行链

```text
一次语义入口：direct / delegate / workflow / revise
  -> 任务合同 + 当前会话/用户绑定
  -> PostgreSQL 任务、独立子会话和版本
  -> 后台队列租约 + 心跳 + 失去租约后的写入拦截
  -> 按依赖启动，跨任务共享本进程容量限制
  -> 专家独立容器 / 上游只读文件快照
  -> 宿主格式校验 + 独立 Agent 验收 + 有限修复
  -> 唯一文件投递意图 + QQ 回执 / 群文件核对
  -> 最终文字进入现有消息 Outbox
```

普通聊天不用额外分类模型；第一次回答同时决定执行方式。复杂任务接受后马上返回 task 编号，
后台继续处理并通过 `say` 报告实际进展。没有 Redis，也不引入另一套 Agent 框架。

## 管理与修订

- `AI_SUBAGENTS_ENABLED=true`、`AI_SUBAGENT_ENTRY_ENABLED=true` 开启自动入口。
- 后台工作流需要现有持久任务与投递存储。启动日志应出现 `subagent-workflows` 后台任务。
- 建议 `AI_SUBAGENT_MAX_TOOL_ROUNDS=20`、`AI_SUBAGENT_TIMEOUT_SECONDS=1800`。
- 每个逻辑任务有总截止时间，重启不能无限重置执行预算；修订创建新版本及新截止时间。
- 控制台选任务后可设置任务默认或单独角色模型，运行中不改变已执行步骤的策略。
- 自动模式排除 Sol。首选模式可降级；锁定模式只允许指定 profile。媒体角色只选声明有视觉的模型。
- 模型策略使用任务版本 CAS，管理接口还使用资源版本和审计；版本冲突需重新载入。
- 原发起人在原会话内续作，入口照抄宿主提供的 task 与步骤编号。管理员可从控制台选择步骤追加要求。
- 修改步骤会使其所有下游重新执行；不相关分支复用旧结果，子会话保留，旧交付物仍有快照。
- 首版之前的任务没有持久派发身份信息，不强行伪造自动恢复；保留旧手动恢复能力。

## 文件和安全

快照目录是 Bot state directory 下的 `subagent_artifacts/<task_id>/<sha256>`。
任务与用户授权由数据库记录决定；模型不能传一个别人的 task id 读取文件。发送由宿主执行，
子任务只返回产物。目录应纳入现有备份，当前不自动删除历史快照，管理员需关注磁盘占用。

高级沙盒以 uid 1000 运行，交接快照由宿主以 root 安装到容器的只读路径；安装使用 no-follow
文件描述符，拒绝符号链接路径。其他 Agent 的容器所有者不同。普通底座镜像不支持只读交接，
这种情况返回明确错误，不退化为共享可写目录。容器不是虚拟机，仍依赖 Docker 和宿主安全配置。

文件完整性、非空、格式、PDF 字体和可渲染性是确定性检查；功能是否符合描述还由独立 Agent
结合真实工具结果评审。不能据此宣称所有功能都经过完备证明，也不能把模型自报成功当成通过。
上传意图先落库；未知回执不会重发，后台按唯一文件名、大小和上传者核对，只把明确匹配记为确认。
这是避免重复发送的策略，不是对 QQ 提供 exactly-once 的承诺。

当前容量控制针对 h610 单 Bot 进程：最多 6 个执行专家，同群最多 3 个，同计划模型最多 2 个。
工作流 worker 与其他后台任务按 kind 隔离领取，容量等待不会阻塞其他可运行组。若扩展成多个
Bot 进程，还需数据库级资源预留，不能把本进程信号量当成分布式全局限流。

## 上线检查

1. 备份数据库，执行 Alembic 到 `0018_subagent_controls`。变更均为新增表及扩展任务状态。
2. 重启 Bot，检查 `subagent-workflows`、普通 durable-jobs 和投递循环都在运行。
3. 查看新任务是否进入 queued，角色是否使用自己的模型和上下文版本。
4. 文件验收不通过应显示 partial，不应直接发到群里；未知上传应等待核对而不是重发。
5. 执行图显示实际开始/结束时间；模型下拉框和追加要求在 SSE 更新时保留草稿。

相关单测：`tests.test_subagent_runtime_v2`、`tests.test_subagent_v2`、`tests.test_subagents`。
页面验证：先在 admin-ui 运行 `npm run build`，再用可用的 Playwright 运行
`node tools/verify_subagent_ui.cjs`；可用 `PLAYWRIGHT_MODULE` 和 `CHROME_EXECUTABLE` 指定本机运行时。
测试使用合成任务，不连接真实群聊，不产生模型费用。
