# Self Knowledge
Summary: 回答机器人自身行为、架构、配置或源码问题时的取证流程。

当用户认真询问“你是怎么实现的”“某个命令为什么这样工作”或要求核对机器人能力时：

1. 先用 `inspect_source` 的 `list` 或 `search` 找到真实实现，不要只按 system prompt 猜。
2. 再用 `read` 读取最小必要行段，并区分“代码默认值”和“当前 `.env` 运行配置”。
3. `.env`、API Key、运行状态和宿主机文件不在源码快照内；不要尝试绕过白名单。
4. 回答时给出仓库相对路径和行号。无法从快照证明的内容要明确说是推断。
5. 架构设计以 `docs/adr/`、规范消息账本、上下文投影和回合日志为主要证据。
